# Security policy

The toolkit holds sign-in sessions and user-written drafts and comments. Neither it nor the contract it reads has been audited.

## Reporting a vulnerability

Please report privately, not in a public issue: use GitHub's "Report a vulnerability" button on this repository's Security tab (private vulnerability reporting). Include what you found, how to reproduce it, and what an attacker could do.

There is no bug bounty, and no response time is promised; reports are handled on a best-effort basis by volunteers. Please give maintainers a reasonable time to fix an issue before disclosing it.

Only testnet deployments exist. Never test against accounts or funds that are not yours.
