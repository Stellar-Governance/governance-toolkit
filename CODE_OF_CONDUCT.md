# Code of conduct

Everyone taking part in this project, in issues, pull requests, reviews and discussion, is expected to:

- be respectful and patient, especially with newcomers;
- discuss ideas and code, not people;
- accept that maintainers decide what is merged, and explain disagreement calmly;
- keep other people's personal information private.

Harassment, insults, discrimination and sharing someone's private information are not accepted.

Report problems privately to the maintainers through the repository's Security tab ("Report a vulnerability") or by e-mail to an address listed on the maintainers' GitHub profiles. Maintainers may remove comments, close threads, or block accounts that break these rules.
